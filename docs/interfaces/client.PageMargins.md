# Interface: PageMargins

## Properties

| Property                      | Type     | Description          |
| ----------------------------- | -------- | -------------------- |
| <a id="bottom"></a> `bottom?` | `string` | Default: `"19.1mm"`. |
| <a id="left"></a> `left?`     | `string` | Default: `"17.8mm"`. |
| <a id="right"></a> `right?`   | `string` | Default: `"17.8mm"`. |
| <a id="top"></a> `top?`       | `string` | Default: `"19.1mm"`. |
