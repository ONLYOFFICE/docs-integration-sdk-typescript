# client

The HTTP client of the document server: conversion, commands, the document builder,
downloading files, the health check and what the server says of itself. Imported from
`@onlyoffice/docs-integration-sdk/client`.

## Classes

| Class                                                               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [BuilderError](classes/BuilderError.md)                             | The builder service answered `200 OK` with an error code. Thrown by [DocumentServerClient.docbuilder](classes/DocumentServerClient.md#docbuilder) and [DocumentServerClient.docbuilderFromFile](classes/DocumentServerClient.md#docbuilderfromfile). The message names the code and what it means.                                                                                                                                                                                                                                  |
| [CommandError](classes/CommandError.md)                             | The command service answered `200 OK` with an error code. Thrown by [DocumentServerClient.command](classes/DocumentServerClient.md#command) for any code but `0` and `4`. The message names the code and what it means.                                                                                                                                                                                                                                                                                                             |
| [ConversionError](classes/ConversionError.md)                       | The conversion service answered `200 OK` with an error code. Thrown by [DocumentServerClient.convert](classes/DocumentServerClient.md#convert) and [DocumentServerClient.convertFromFile](classes/DocumentServerClient.md#convertfromfile). The message names the code and what it means.                                                                                                                                                                                                                                           |
| [DocumentServerClient](classes/DocumentServerClient.md)             | The client of the document server. Each method calls one endpoint, parses the answer into the type the endpoint promises, and rejects when the document server reports a failure: in the status, or in a `200 OK` body, as the conversion, command and builder services do.                                                                                                                                                                                                                                                         |
| [DocumentServerError](classes/DocumentServerError.md)               | The base class of every error a client call rejects with: a failure the document server reports, an answer that is not the promised one, or no answer at all.                                                                                                                                                                                                                                                                                                                                                                       |
| [DocumentServerHttpError](classes/DocumentServerHttpError.md)       | The document server answered with a status outside the 2xx range. The message names the status, the URL and the beginning of the body.                                                                                                                                                                                                                                                                                                                                                                                              |
| [DocumentServerNetworkError](classes/DocumentServerNetworkError.md) | No answer came: the document server can't be reached, or the connection broke before the answer was read, the body included.                                                                                                                                                                                                                                                                                                                                                                                                        |
| [DocumentServerParseError](classes/DocumentServerParseError.md)     | A 2xx body is not the JSON the endpoint promises: not JSON at all, or JSON of another shape. Expect it even in a healthy integration: a reverse proxy may answer `200 OK` with a page of its own. For a body that is not JSON, the parse error is the `cause`.                                                                                                                                                                                                                                                                      |
| [DocumentServerRawClient](classes/DocumentServerRawClient.md)       | The same endpoints as [DocumentServerClient](classes/DocumentServerClient.md), returning the untouched `Response`. It never rejects on what the document server answers, only when no answer comes: with [DocumentServerNetworkError](classes/DocumentServerNetworkError.md), with [DocumentServerTimeoutError](classes/DocumentServerTimeoutError.md), or with the reason of your `signal` when you cancel the call. A `timeoutMs` in the call options that is not a whole number from 1 to 2147483647 rejects with a `TypeError`. |
| [DocumentServerTimeoutError](classes/DocumentServerTimeoutError.md) | The deadline, `timeoutMs`, passed before the answer was read. The `DOMException` named `"TimeoutError"` is the `cause`.                                                                                                                                                                                                                                                                                                                                                                                                             |
