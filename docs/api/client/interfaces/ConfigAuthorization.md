# Interface: ConfigAuthorization

Where the document server expects the JWT of a request.

## Properties

| Property                              | Type     | Description                                                       |
| ------------------------------------- | -------- | ----------------------------------------------------------------- |
| <a id="property-header"></a> `header` | `string` | Name of the header carrying the token, such as `"Authorization"`. |
| <a id="property-prefix"></a> `prefix` | `string` | Prefix the token is written behind, such as `"Bearer "`.          |
