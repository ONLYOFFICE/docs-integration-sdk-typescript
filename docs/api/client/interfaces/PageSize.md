# Interface: PageSize

## Properties

| Property                               | Type     | Description         |
| -------------------------------------- | -------- | ------------------- |
| <a id="property-height"></a> `height?` | `string` | Default: `"297mm"`. |
| <a id="property-width"></a> `width?`   | `string` | Default: `"210mm"`. |
