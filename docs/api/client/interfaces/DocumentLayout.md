# Interface: DocumentLayout

Layout of a form printed to PDF or to an image.

## Properties

| Property                                                     | Type      | Description                                               |
| ------------------------------------------------------------ | --------- | --------------------------------------------------------- |
| <a id="property-drawformhighlight"></a> `drawFormHighlight?` | `boolean` | Highlight the form fields.                                |
| <a id="property-drawplaceholders"></a> `drawPlaceHolders?`   | `boolean` | Draw the placeholders of the form fields.                 |
| <a id="property-isprint"></a> `isPrint?`                     | `boolean` | Render as if printed, DOCX to PDF only. Default: `false`. |
