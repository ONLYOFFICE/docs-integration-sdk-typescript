# Interface: WatermarkRun

A styled piece of watermark text.

## Properties

| Property                                         | Type                                      | Description                                  |
| ------------------------------------------------ | ----------------------------------------- | -------------------------------------------- |
| <a id="property-bold"></a> `bold?`               | `boolean`                                 | Bold text.                                   |
| <a id="property-fill"></a> `fill?`               | [`RgbColor`](../type-aliases/RgbColor.md) | Highlight of the text, in RGB.               |
| <a id="property-font-family"></a> `font-family?` | `string`                                  | Font name, such as `"Arial"`.                |
| <a id="property-font-size"></a> `font-size?`     | `string` \| `number`                      | Font size in points.                         |
| <a id="property-italic"></a> `italic?`           | `boolean`                                 | Italic text.                                 |
| <a id="property-strikeout"></a> `strikeout?`     | `boolean`                                 | Struck-out text.                             |
| <a id="property-text"></a> `text?`               | `string`                                  | The text itself. `<%br%>` starts a new line. |
| <a id="property-underline"></a> `underline?`     | `boolean`                                 | Underlined text.                             |
