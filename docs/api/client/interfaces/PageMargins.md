# Interface: PageMargins

Page margins, in CSS-like units such as `"17.8mm"`.

## Properties

| Property                               | Type     | Description          |
| -------------------------------------- | -------- | -------------------- |
| <a id="property-bottom"></a> `bottom?` | `string` | Default: `"19.1mm"`. |
| <a id="property-left"></a> `left?`     | `string` | Default: `"17.8mm"`. |
| <a id="property-right"></a> `right?`   | `string` | Default: `"17.8mm"`. |
| <a id="property-top"></a> `top?`       | `string` | Default: `"19.1mm"`. |
